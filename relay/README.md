# Сервис приглашений для тестовой ветки

Каждая личная папка Google Диска подключается через её обычный адрес. Обе стороны вводят адрес в GameSaves. Владелец открывает «Я владелец этой папки», копирует личный код устройства, входит в Google и выбирает ту же папку. После этого он видит заявки с ником и номером устройства. При совпадающих никах можно сверить номер с другом. До одобрения доступны только состояние собственной заявки и её номер. Новые подключения получают персональные ключи. Разрешения в интерфейсе Google Диска можно оставить ограниченными.

## Развёртывание оператором

1. Создайте HTTPS-сервис из Dockerfile в этой папке. Подключите постоянное хранилище по пути /data, доступное пользователю node. Запускайте одну реплику. Настройте ограничение частоты запросов и размера тела (32 МиБ) на входе. Сохраняйте резервные копии базы и ключа шифрования.
2. В Google Cloud включите Drive API и Google Picker API. Создайте OAuth client типа Web application. Разрешите HTTPS origin своего сервиса и redirect URI с путём /callback. Настройте экран согласия и тестовых пользователей на период тестирования. Для Picker создайте API key, ограниченный вашим origin и Google Picker API.
3. Укажите PUBLIC_ORIGIN, GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, PICKER_KEY, PROJECT_NUMBER. STORE_KEY — 32 случайных байта в hex, например результат openssl rand -hex 32. Секреты задаются в настройках хостинга. Для запуска без Docker нужен Node 24 и путь DATABASE для SQLite.
4. Установите переменную GitHub Actions GAMESAVES_GROUP_ORIGIN в HTTPS origin сервиса и пересоберите демоприложение. Можно также задать GAMESAVES_GROUP_ORIGIN в окружении приложения при запуске. Проверяйте подключение начиная с поля ссылки в программе.
5. Проверьте с двумя тестовыми профилями, что отправка игрока видна у друга и что восстановление возвращает исходное содержимое сейва. Облако принимает архивы до 32 МиБ. История показывает версии, отправленные именно в эту группу через GameSaves.

Тест протокола с тестовым ответом Google запускается командой `node --test relay/protocol.test.mjs` из корня проекта. Для проверки реальных разрешений требуется отдельная проверка на аккаунте владельца.
