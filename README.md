# Игровые сохранения

Приложение на Rust для Windows x64. GameSaves хранит историю игровых сохранений и загружает сейвы напрямую на Google Диск.

[Скачать Windows x64 из Releases](https://github.com/RadioVanya71/GameSaves/releases/latest). Распакуйте ZIP и запустите `game-saves.exe`.

Чтобы попробовать программу без установленных игр, нажмите **Деморежим**. Профили игрока и друга используют отдельные настройки. В обычном режиме программа открывает библиотеку и настройки предыдущей стабильной версии.

## Настройка один раз

1. На обоих ПК запустите `game-saves.exe` и выберите игру в каталоге слева. Если библиотека пуста, нажмите **Добавить игру** или **Повторить поиск на ПК**. Приложение ищет установки Steam, Epic Games и GOG. Игру из другого источника можно добавить вручную.
2. Для Subnautica 2 и папок мира Valheim 1.0 программа подхватывает единственный найденный сейв автоматически. Если найдено несколько, выберите нужный мир в карточке. Если у получателя ещё нет сейва, сначала сохранитесь в игре. Для остальных игр можно указать файл или папку вручную.
3. Нажмите **Подключить Google Диск**. В браузере подтвердите доступ и выберите папку. GameSaves сохранит доступ для следующих запусков. Устанавливать клиент Google Диска не требуется.

Обложки загружаются автоматически для игр Steam и GOG, если магазин отдаёт изображение. Для Subnautica 2 обложка доступна также при установке вне Steam. В настройках любой игры можно выбрать свой JPG, PNG или WebP. Скачанные обложки кешируются на ПК.

## Обмен

- Закрой игру и нажми **Отправить сохранение** после подключения Google Диска или в деморежиме.
- Полученные версии появляются автоматически. Друг закрывает игру и нажимает **Восстановить версию**. Предыдущий файл остаётся рядом как `savesync-backup-*.bak`.

Программа хранит каждую отправку отдельно. Если вы поиграли в своих копиях мира, обе версии можно выбрать в списке.

Для мира из нескольких файлов укажите папку только одного мира на обоих ПК. При восстановлении папки архив заменяет её целиком, резервная копия предыдущей папки сохраняется рядом. Для однофайловых сохранений поддерживаются архивы версии 0.5.

## Ники и история

Укажите **Мой ник** в верхней панели. Новые версии в истории будут подписаны этим именем. Прямая загрузка работает от имени Google-аккаунта, которому разрешено записывать в выбранную папку. Программа показывает архивы, созданные GameSaves для выбранной игры и доступные подключённому Google-аккаунту.

## Регистрация входа для тестовой сборки

Для кнопки подключения требуется Desktop app OAuth client в проекте Google с включёнными Google Drive API и Google Picker API. При разработке можно импортировать JSON такого клиента через кнопку **Выбрать JSON регистрации Google**. Для сборки с готовой кнопкой оператор задаёт GAMESAVES_GOOGLE_CLIENT_ID как переменную GitHub Actions, а GAMESAVES_GOOGLE_CLIENT_SECRET как секрет GitHub Actions. Это поля регистрации Desktop app. Токены аккаунта в сборку не включаются. Включите тестовые аккаунты в настройках согласия, если проект Google в режиме Testing. Токен пользователя сохраняется на Windows с DPAPI.

## Сборка из исходников

В корне репозитория выполните `cargo build --locked --release` с Rust 1.100. Готовый файл появится в `target/release`. Проверки запускаются командой `cargo test --locked`.
