# GameSaves

**Резервные копии игровых сохранений на Google Диске.** GameSaves для Windows собирает файл сохранения или папку мира в ZIP, показывает историю версий и восстанавливает выбранную копию.

[Скачать GameSaves для Windows x64](https://github.com/RadioVanya71/GameSaves/releases/latest) · [Сайт проекта](https://radiovanya71.github.io/GameSaves/) · [Политика конфиденциальности](https://radiovanya71.github.io/GameSaves/privacy.html)

## Быстрый старт

1. Распакуйте ZIP и запустите `game-saves.exe`.
2. Выберите игру в библиотеке или нажмите **«Добавить»**. Если GameSaves находит один сейв, он подхватывает его автоматически. Если найдено несколько, выберите свой мир или слот. Для игр без автопоиска укажите файл сохранения или папку одного мира вручную.
3. Нажмите **«Подключить Google Диск»**, подтвердите доступ в браузере и выберите папку для архивов. Если папку уже прислали, откройте **«Подключить по ссылке»**, вставьте ссылку и подтвердите выбор в Google. Приложение запомнит подключение. Устанавливать клиент Google Диска не требуется.
4. Сохранитесь в игре, закройте её и нажмите **«Отправить сохранение»**.

## История и восстановление

Каждая отправка создаёт отдельный архив. В истории видны дата и ник отправителя. Ник можно задать в верхней панели через **«Мой ник»**.

Для отката закройте игру, выберите запись в **«Истории версий»** и нажмите **«Восстановить версию»**. GameSaves сохранит предыдущий сейв рядом как резервную копию. Если сохранение занимает целую папку, восстановление заменяет папку мира целиком.

Для общей папки каждый участник подключает её через Google. Для отправки нужно право записи. В истории видны версии, созданные GameSaves для выбранной игры и доступные через подключённый аккаунт. Если архив друга виден на Диске, а в списке его нет, нажмите **«Добавить архивы с Диска»** и выберите его через Google. Прогресс независимых копий мира автоматически не объединяется.

## Библиотека

GameSaves ищет установки из Steam, Epic Games и GOG. Другие игры можно добавить вручную. Обложки загружаются из поддерживаемых источников. Свою картинку можно выбрать в разделе **«Сохранение и обложка»**.

## Разработка

Проект написан на Rust. Для сборки и тестов используйте Rust 1.100:

```sh
cargo test --locked
cargo build --locked --release
```

Готовый файл Windows появится в `target/release/game-saves.exe`. Для сборки со входом в Google нужны регистрация **Desktop app** и включённые **Google Drive API** и **Google Picker API**. GitHub Actions берёт `GAMESAVES_GOOGLE_CLIENT_ID` из переменных репозитория и `GAMESAVES_GOOGLE_CLIENT_SECRET` из секретов. Доступ пользователей хранится на их компьютерах.
