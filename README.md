# Игровые сохранения

Приложение на Rust для Windows x64. GameSaves передаёт игровые сохранения между друзьями напрямую или через общую папку.

[Скачать Windows x64 из Releases](https://github.com/RadioVanya71/GameSaves/releases/latest). Распакуйте ZIP и запустите `game-saves.exe`.

Чтобы попробовать программу без установленных игр, нажмите **Деморежим**. Профили игрока и друга используют отдельные настройки. В обычном режиме программа открывает библиотеку и настройки предыдущей стабильной версии.

## Настройка один раз

1. На обоих ПК запустите `game-saves.exe` и выберите игру в каталоге слева. Если библиотека пуста, нажмите **Добавить игру** или **Повторить поиск на ПК**. Приложение ищет установки Steam, Epic Games и GOG. Игру из другого источника можно добавить вручную.
2. Выберите **файл сохранения** или **папку одного мира** и нажмите **Запомнить путь**. Для Subnautica 2 приложение предлагает найденные `savegame_*.sav`. Если у получателя пока нет подходящего слота, сначала создайте его в игре.
3. В разделе **Настройки игры** укажите одну общую папку с правом записи для обоих и одинаковый код мира. Пути на ПК могут различаться. Для разных миров используйте разные коды. Папка, которую оба синхронизируют через облачный клиент, подойдёт для обмена с отключённым ПК.

Обложки загружаются автоматически для игр Steam и GOG, если магазин отдаёт изображение. Для Subnautica 2 обложка доступна также при установке вне Steam. В настройках любой игры можно выбрать свой JPG, PNG или WebP. Скачанные обложки кешируются на ПК.

## Обмен

- Сохранись, закрой игру и нажми **Отправить сохранение**. Если программа у друга открыта и есть прямое соединение, сейв поступит на его ПК. Для установления связи приложение использует iroh. Для первого соединения файлы с адресами обоих ПК должны успеть синхронизироваться в общей папке.
- Если друг отключился или прямое соединение недоступно, архив автоматически записывается в общую папку. Дождись, пока облачный клиент завершит загрузку, если собираешься выключить ПК.
- Полученные версии появляются автоматически. Друг закрывает игру и нажимает **Восстановить версию**. Предыдущий файл остаётся рядом как `savesync-backup-*.bak`.

Программа хранит каждую отправку отдельно. Если вы поиграли в своих копиях мира, обе версии можно выбрать в списке.

Для мира из нескольких файлов укажите папку только одного мира на обоих ПК. При восстановлении папки архив заменяет её целиком, резервная копия предыдущей папки сохраняется рядом. Для однофайловых сохранений поддерживаются архивы версии 0.5. Автоматическая доставка через облако зависит от того, как общая папка синхронизируется между ПК.

## Имена и приглашения

Укажите **Мой ник** в верхней панели и сохраните его. Новые версии в истории будут подписаны этим именем.

Для групп Google Диска нужен работающий HTTPS-сервис приглашений и настроенный Google OAuth. Владелец один раз выбирает папку в браузере, остальные вводят приглашение GameSaves. Обычная ссылка на папку не даёт клиенту доступа к загрузке сейвов. В релизе публичный сервис не настроен. Для своего сервиса задайте переменную окружения GAMESAVES_GROUP_ORIGIN перед запуском или в GitHub Actions перед сборкой. Лимит сервиса составляет 32 МиБ на архив. [Настройка сервиса](relay/README.md).

## Сборка из исходников

В корне репозитория выполните `cargo build --locked --release` с Rust 1.100. Готовый файл появится в `target/release`. Проверки запускаются командой `cargo test --locked`.
